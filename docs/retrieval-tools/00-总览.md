# 检索工具集 · 总览

> 你（负责检索工具）要做的事，一句话：**造一套能查知识库的检索工具，先独立做好，后续让同事用 eve 的 agentic 自动调用、或单独调用都行。**

---

## 1. 为什么要做这个

eve 框架（同事用来搭智能体的）**不带任何检索/知识库能力**（已核实官方文档，见 [`./99-完整设计参考.md` §0.1](./99-完整设计参考.md)）。

eve 只提供"工具调用机制"（插座），知识库检索能力（电器）一个都不送，必须我们自己造。这就是这套工具存在的意义。

---

## 2. 要造什么（4 个部分）

| 部分 | 是什么 | 大白话 | 依赖 eve 吗 |
| --- | --- | --- | --- |
| **① 嵌入服务** | 把文本变成向量 | "冰箱的压缩机"——把文字转成数字向量 | ❌ 独立 |
| **② 存储与入库** | 把文档存成向量入库 | "往冰箱里放食材"——文档→切片→向量→存库 | ❌ 独立 |
| **③ 检索引擎** | 查的时候找出最像的 | "从冰箱里精准取食材"——query→向量→找最像的几段 | ❌ 独立 |
| **④ eve 工具封装** | 包装成 eve 工具 | "装上插头"——让 agentic 能自动选用、也能单独调用 | ✅ 仅这步 |

**前 3 部分完全独立**，不碰 eve、不碰同事的代码，你现在就能做。
**第 4 部分**是把前三部分的能力"装上插头"，让同事后续接得上。

---

## 3. 怎么用（两种用法都支持）

这是核心设计目标：**一套工具，两种用法。**

```
                    ┌─────────────────────────────┐
                    │  检索能力核心逻辑（lib/）     │  ← 纯函数，谁都能调
                    │  vectorSearch()              │
                    │  keywordSearch()             │
                    │  hybridSearch()              │
                    └──────────────┬──────────────┘
                           ┌───────┴────────┐
                           ▼                ▼
                   ┌───────────────┐  ┌─────────────────┐
            用法A  │ eve 工具封装   │  │ 单独调用         │  用法B
   agentic 自动选用 │ defineTool    │  │ 在任意 API/代码  │
                   │ 模型自己决定调 │  │ 里直接 import 调 │
                   └───────────────┘  └─────────────────┘
```

- **用法 A（agentic）**：同事把工具文件放进 `agent/tools/`，eve 自动让模型根据用户问题选用哪个工具。**模型决定调不调、调哪个。**
- **用法 B（单独调用）**：在任何普通代码里（比如一个 API 接口、一个脚本）直接 import 检索函数调用，不经过模型。**代码决定调。**

> 关键设计原则：**核心检索逻辑写成纯函数放在 `lib/`，eve 工具只是它的薄包装。** 这样 agentic 和单独调用共用同一套逻辑，不重复造。

## 5. 建议的开发顺序

```
01 嵌入服务  →  02 存储与入库  →  03 检索引擎  →  04 eve 封装
   (先把文本能变向量)   (再让向量能存进去)   (然后能查出来)   (最后装上插头)
```

每一步都能独立验证：
- 做完 01：能给一句话，返回向量 ✅
- 做完 02：能往库里塞一份文档，看到切片和向量 ✅
- 做完 03：能输入问题，返回最像的几段 ✅
- 做完 04：agentic 能自动调它 ✅

---

## 6. 和同事的关系

- **现在**：你独立做 01–04，不需要等他、不需要对接。
- **后续**：他把 04 的工具文件放进他的 `agent/tools/`，就能用；或者在任意代码里 import 你的检索函数单独用。
- **他要提供的（仅联调时）**：登录后的用户/租户身份（用于数据隔离），但这是 04 联调阶段的事，不影响你现在做 01–03。
