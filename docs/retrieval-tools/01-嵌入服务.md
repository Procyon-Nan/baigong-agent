# 01 · 嵌入服务（把文本变成向量）

> 检索的第一步：**必须把文字变成一串数字（向量）**，计算机才能算"两段话有多像"。
> 这一步叫"嵌入（embedding）"。本篇讲怎么做它。

---

## 1. 为什么需要嵌入

向量检索的原理很简单：
```
文档 "报销政策"  →嵌入→  [0.12, 0.85, 0.33, ...] （一串数字）
用户问 "怎么报销" →嵌入→  [0.11, 0.83, 0.35, ...] （一串数字）
                          ↓
              两串数字越接近，说明两段话意思越像
```

所以**每段入库的文档**和**用户的每个问题**，都要先变成向量。

---

## 2. 用什么模型

有两条路，**不冲突，按阶段切换**：

| 路线 | 适用阶段 | 说明 |
| --- | --- | --- |
| **A. 模型商免费额度**（如 Qwen/智谱/百度等） | **开发期 / 跑通原型** | 注册即送免费额度，零部署、当天就能调通，最快验证检索效果 |
| **B. 自建 Qwen3-Embedding** | **生产期** | 你已有算力；数据不出境、无按量计费、高并发可控 |

> **核心原则：入库嵌入和查询嵌入必须用同一个模型、同一维度**（否则相似度算出来是错的）。
> ⚠️ **重要**：从 A 切到 B（或反之）等于换了模型，**已入库的向量必须全部重新嵌入**。所以"用免费额度跑原型"和"上自建"之间切换的代价是重建索引——开发期无所谓，生产期要慎重。

### 2.1 关键认知：查询嵌入是"高频在线"路径，不是只跑一次

| | 入库嵌入 | 查询嵌入 |
| --- | --- | --- |
| 什么时候跑 | 文档进库时（一次性） | **用户每次提问都跑一次** |
| 要求 | 量可以大，慢点没事 | **要快（目标 <100ms），且不能挂** |

所以自建服务要保证：① 低延迟；② 高可用；③ 出故障时有降级（向量挂了，退回用关键词检索）。

---

## 3. 接口设计（核心：抽成可切换的接口层）

**这是本篇最重要的一点**：嵌入能力抽成一个**接口**，后端实现可以切换。
- **开发期**：后端 = 模型商免费额度（最快跑通，零部署）。
- **生产期**：后端 = 自建 Qwen3 服务（数据不出境、成本可控）。
- **切换时**：只改 `embedder-instance.ts` 一个文件，**上层检索代码一行不改**（但需重建已入库的向量）。

```
src/server/retrieval/embedder.ts        接口定义
  ├─ 实现: provider-api.ts              开发期首选：调模型商 embedding API（免费额度）
  ├─ 实现: self-hosted-qwen.ts          生产期：调自建 Qwen3 服务
  └─ 实现: inference-cluster.ts         未来扩容：多副本集群（暂不写）
```

> **建议起步顺序**：先用「模型商免费额度」把整条检索链路（01→02→03→04）跑通、验证检索效果；确认方案 OK 后，再部署自建 Qwen3、重建索引切到生产后端。这样不被"自建服务还没搭好"卡住。

### 3.1 接口定义（代码骨架）

```ts
// src/server/retrieval/embedder.ts
/**
 * 嵌入服务接口。
 * 无论后端是自建 Qwen3 还是模型商 API，对外都是这个接口。
 * 上层（入库流水线、检索引擎）只认这个接口，不关心后端是谁。
 */

/** 单条嵌入输入 */
export interface EmbedInput {
  text: string;
}

/** 嵌入结果 */
export interface EmbedResult {
  vector: number[];      // 向量
  dim: number;           // 维度
  model: string;         // 用的哪个模型（便于排查）
}

/** 嵌入器接口：所有实现都要满足这个形状 */
export interface Embedder {
  /** 把一段文本变成向量 */
  embed(text: string): Promise<EmbedResult>;
  /** 批量嵌入（入库时用，比一条条调快得多） */
  embedBatch(texts: string[]): Promise<EmbedResult[]>;
  /** 当前用的模型名和维度（入库时要记录，保证一致） */
  readonly model: string;
  readonly dim: number;
}
```

### 3.2 首版实现（接自建 Qwen3，代码骨架）

```ts
// src/server/retrieval/embedders/self-hosted-qwen.ts
import type { Embedder, EmbedResult } from "../embedder";

/**
 * 自建 Qwen3-Embedding 实现。
 * 调用你部署的嵌入服务（假设它暴露了一个 HTTP 接口）。
 */
export function createSelfHostedQwenEmbedder(config: {
  endpoint: string;      // 自建服务地址，如 http://localhost:8001/embed
  model: string;         // 模型名
  dim: number;           // 向量维度
  timeoutMs?: number;    // 超时，默认 5000
}): Embedder {
  const timeoutMs = config.timeoutMs ?? 5000;

  async function callApi(texts: string[]): Promise<number[][]> {
    const controller = new AbortController();
    const timer = setTimeout(() => controller.abort(), timeoutMs);
    try {
      const res = await fetch(config.endpoint, {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({ model: config.model, input: texts }),
        signal: controller.signal,
      });
      if (!res.ok) throw new Error(`embed 服务返回 ${res.status}`);
      const json = await res.json();
      return json.vectors as number[][];
    } finally {
      clearTimeout(timer);
    }
  }

  return {
    model: config.model,
    dim: config.dim,
    async embed(text: string): Promise<EmbedResult> {
      const [vec] = await callApi([text]);
      return { vector: vec, dim: config.dim, model: config.model };
    },
    async embedBatch(texts: string[]): Promise<EmbedResult[]> {
      const vecs = await callApi(texts);
      return vecs.map((vector) => ({ vector, dim: config.dim, model: config.model }));
    },
  };
}
```

### 3.3 模型商 API 实现（开发期首选，用免费额度）

以**阿里云百炼（DashScope）的 Qwen Embedding** 为例（兼容 OpenAI 接口格式，国内可直连）：

```ts
// src/server/retrieval/embedders/provider-api.ts
import type { Embedder, EmbedResult } from "../embedder";

/**
 * 模型商 embedding API 实现（开发期用免费额度快速跑通）。
 * 这里以阿里云 DashScope（兼容 OpenAI /embeddings 接口）为例。
 * 换别的模型商（智谱、百度等）时，改 endpoint / model / 解析逻辑即可。
 *
 * 注意：API Key 走环境变量，绝不写进代码。
 */
export function createProviderApiEmbedder(config: {
  endpoint: string;      // 如 https://dashscope.aliyuncs.com/compatible-mode/v1/embeddings
  apiKeyEnv: string;     // 环境变量名，如 "DASHSCOPE_API_KEY"
  model: string;         // 如 "text-embedding-v3"
  dim: number;           // 该模型的输出维度
  timeoutMs?: number;
}): Embedder {
  const timeoutMs = config.timeoutMs ?? 10000;

  async function callApi(texts: string[]): Promise<number[][]> {
    const apiKey = process.env[config.apiKeyEnv];
    if (!apiKey) throw new Error(`缺少环境变量 ${config.apiKeyEnv}`);
    const controller = new AbortController();
    const timer = setTimeout(() => controller.abort(), timeoutMs);
    try {
      const res = await fetch(config.endpoint, {
        method: "POST",
        headers: {
          "Content-Type": "application/json",
          "Authorization": `Bearer ${apiKey}`,
        },
        body: JSON.stringify({ model: config.model, input: texts }),
        signal: controller.signal,
      });
      if (!res.ok) throw new Error(`模型商 embed 返回 ${res.status}: ${await res.text()}`);
      const json = await res.json();
      // OpenAI 兼容格式：json.data[i].embedding
      return (json.data as { embedding: number[] }[])
        .sort((a, b) => 0)  // 如需保持顺序按 index 排序
        .map((d) => d.embedding);
    } finally {
      clearTimeout(timer);
    }
  }

  return {
    model: config.model,
    dim: config.dim,
    async embed(text: string): Promise<EmbedResult> {
      const [vec] = await callApi([text]);
      return { vector: vec, dim: config.dim, model: config.model };
    },
    async embedBatch(texts: string[]): Promise<EmbedResult[]> {
      const vecs = await callApi(texts);
      return vecs.map((vector) => ({ vector, dim: config.dim, model: config.model }));
    },
  };
}
```

> **API Key 管理**：开发期用模型商时，Key 放本地 `.env`（已 gitignore，不进仓库）；生产期若也用模型商，Key 由管理员后台加密配置（遵守 P0 §8，不进代码/日志/Prompt）。

## 4. 你需要做的事

**开发期（用模型商免费额度，最快起步）：**
1. 选一个模型商（见文末「免费额度参考」），注册拿 API Key。
2. 把 Key 放进本地 `.env`（如 `DASHSCOPE_API_KEY=sk-xxx`）。
3. 写 `embedder.ts`（接口）、`provider-api.ts`（实现）、`embedder-instance.ts`（出口）三个文件。
4. 确认所选模型的输出维度，填到 `dim`。**这个数字必须和建表时的向量列维度一致。**

**生产期（切自建 Qwen3）：**
1. 在自有算力上部署 Qwen3-Embedding，暴露 HTTP 接口。
2. 写 `self-hosted-qwen.ts`，在 `embedder-instance.ts` 切换到它。
3. **重建已入库的向量**（重新跑一遍入库流水线）。

---

## 5. 怎么验证做对了

写个临时脚本，能跑通这句就算成功：
```ts
import { embedder } from "../src/server/retrieval/embedder-instance";
const r = await embedder.embed("怎么报销");
console.log(r.vector.length);  // 应等于 dim，比如 1024
console.log(r.vector.slice(0, 5));  // 打印前 5 个数字，确认有值
```

输出一串数字、长度等于维度 → 嵌入服务通了 ✅

## 6. 扩容预留（现在不做，记着）

未来用户量大了撑不住时，升级路径（详见 [`./99-完整设计参考.md` §2.3](./99-完整设计参考.md)）：
- **L1**：给嵌入服务加攒批 + query 缓存。
- **L2**：横向加推理副本，`embedder-instance.ts` 换成连负载均衡地址。
- **L3**：切模型商 API（仅查询侧或全部）。

**关键：扩容优先"加副本"，而不是"换模型"**（换模型 = 已入库向量全废）。
因为接口已经抽好（§3），以上升级都只改实现文件，上层检索代码不动。
